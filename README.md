# StudySpace

A free, responsive student learning hub for Classes 9–12, with official UPMSP syllabus links, chapter/topic revision notes and per-topic PDF downloads. Open to all students; no account or student personal data is required.

## Features
- Chapter/topic selector for Classes 9–12, with simple Hinglish explanations, extra detail on demand, key revision points, worked examples, common mistakes to avoid and formulas where relevant.
- Downloadable PDF revision sheet for the selected chapter/topic, including simple explanations, a sample question and answer, core points, common mistakes, board-study checklist and verified unit weightage where available.
- Class/subject/topic-wise recall quiz: think of the answer first, reveal the worked example and simple explanation, review each key point, and mark whether the topic needs revision.
- Class-wise notes for Mathematics, Science, Social Science, English, senior Physics/Chemistry/Biology, and selected Humanities/Commerce subjects.
- Official UPMSP question-bank and model-paper links for additional board-style practice.
- Links to NCERT textbooks, DIKSHA and SWAYAM.
- Responsive layout and basic accessibility labels.

## Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then Save.
4. Wait for the Pages deployment and open the URL shown in Settings → Pages.

## Board preparation approach
- Quiz questions are drawn from the matching StudySpace revision topics; they are original self-check prompts, not copied official questions.
- The site's “board focus” guidance explains what to learn and practise, but does not claim to predict the board paper.
- Where verified from the official UPMSP 2026–27 subject PDFs, Class 10 unit-level written-paper weightage is shown for Mathematics, Science and Social Science. Unit marks are not guaranteed marks from an individual chapter.
- Official UPMSP question-bank and model-paper pages are linked alongside the quiz for authentic objective and descriptive question practice.

## Google AdSense setup
- `ads.js` contains a guarded Auto Ads loader. Ads are intentionally disabled until the real AdSense client ID (`ca-pub-XXXXXXXXXXXXXXXX`) is configured and Auto Ads is enabled.
- `privacy.html` describes advertising cookies and third-party data use; review and update it before approval if the site's actual data handling changes.
- AdSense only starts serving after the site is added to the account and approved/marked Ready. Do not expect earnings or live ads from the placeholder settings.
- Current GitHub Pages URL uses a repository path (`/StudySpace/`). Google's site URL entry rules do not accept path-based URLs for standard site registration. Consider attaching a custom domain to GitHub Pages before applying. See Google's [site URL rules](https://support.google.com/adsense/answer/2784438) and [site approval guide](https://support.google.com/adsense/answer/12169212).
- After the real publisher ID is supplied, update `ads.js`, create the matching `ads.txt` record if AdSense asks for it, configure Auto Ads in AdSense, and verify the published site.

## Content note
StudySpace is an independent educational resource, not an official school website or a UPMSP product. The notes are original revision aids—not official board-issued notes, a guarantee of exam questions, or a replacement for prescribed textbooks. Official UPMSP PDFs are linked for checking syllabus coverage. Coverage of individual notes is not yet exhaustive for every vocational/elective subject; students should confirm their registered subject combination and the latest official syllabus. External learning links include NCERT, DIKSHA and SWAYAM.
